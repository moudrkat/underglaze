# fractal — no

Generated by `src/fractal.py`. Regenerate, do not hand-edit.

Someone looked at the tendrils and asked whether the whole thing is a fractal.
A fractal needs a dilation symmetry. `p4` is a crystallographic group — discrete
translations, finite point group — and contains no dilation, so the answer was
already fixed when the group was measured. `f` is a finite sum of cosines, hence
analytic, so `{f = θ}` is an analytic curve with box dimension exactly 1 for
every cutoff K. Measured anyway:

```

   the tile                           0.90     0.98     1.08     1.34     1.61     1.71     1.95 
   band-limited K=48  (D=1 exactly)   0.96     0.99     1.02     1.13     1.39     1.56     1.75 
   filtered noise     (D=1)           0.89     0.94     0.98     1.04     1.16     1.49     1.94
```

A single fit across all octaves would report D = 1.34 for the tile and look
fractal. It is the crossover artifact of any dense set of curves, and the tile's
own band-limited reconstruction — smooth by construction — reports it too.
